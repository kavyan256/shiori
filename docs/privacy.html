Privacy

Shiori and its browser extension keep your data on your PC. There is no account, no server of ours, no analytics and no tracking. Last updated 30 October 2026.

What the browser extension reads

The title and address of your open tabs, which tab group they're in, and, on YouTube video pages, how far through the video you are. It reads these so the Shiori app can save your tabs and reopen them later.

Where that goes

Only to the Shiori app on the same computer, at the local address 127.0.0.1. The extension sends nothing to any website or to any other computer, and nothing is sold or shared.

What the Shiori app stores

Your saved desks, notes, and optional pictures of your screen, as plain files in %LOCALAPPDATA%\Shiori. If "Save automatically" is on, it also keeps one file with what's open, replaced every few minutes, so a restart or crash doesn't lose your desk. You can turn off desk pictures and automatic saving from the tray, and delete any of these files at any time. Uninstalling keeps your desks in case you come back, unless you run uninstall.ps1 -RemoveParks.

Your PowerShell profile

Only if you turn on "Remember PowerShell folders" in the tray, Shiori asks first and then adds a small marked block to your PowerShell profile, which notes each tab's current folder in a file on your PC. It keeps a backup of your profile. Unticking it, or uninstalling, removes the block.

The one request Shiori makes

Once a day the app asks GitHub for the number of the latest release, so it can tell you when an update is out. This sends no information about you or your desks, though GitHub sees your IP address like any website does. You can turn it off from the tray with "Check for updates daily".

Questions

Shiori is open source, so you can read exactly what it does: github.com/kavyan256/shiori. Questions are welcome as a GitHub issue.
